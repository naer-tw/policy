1. 戰略突破點（本日新發現）

成少共犯不是「新議題沒處理」，是「舊條款被閒置」。

事實 我國現行法早已建立成年人利用未成年人犯罪之加重制度，散見四部特別法：

法源條文要旨（需以官方版本核對）規範對象
少年事件處理法 §85成年人教唆、幫助、利用未滿 18 歲之人犯罪，或與之共同實施犯罪者，加重其刑至 1/2一般刑事案件
毒品危害防制條例 §9成年人對未成年人犯本條例之罪、引誘或教唆未成年人施用毒品者，加重其刑毒品案件
組織犯罪防制條例 §6 / §6-1招募未成年人加入犯罪組織者加重其刑；指揮、操縱犯罪組織之主從責任組織犯罪、詐欺機房
詐欺犯罪危害防制條例（2024 公布）對指揮詐欺機房、招募未成年參與詐欺之加重條款詐欺集團
刑法 §29、§30、§31教唆犯、幫助犯、身分犯之一般規定全體犯罪

國教盟觀點 成少共犯的法律規範早已存在於四部特別法，但實務上：

  1. 統計黑洞：司法院、法務部、警政署從未公開「成少共犯案件起訴 / 定罪 / 量刑」分類統計，社會無從評估 §85 等條款的真實適用率。
  2. 競合處理不明：少事法 §85 vs 毒品條例 §9 vs 組織犯罪條例 §6 之間如何競合、檢察官如何起訴選用，沒有明文準則。
  3. 偵查程序斷裂：成年人偵查由檢察官主導、少年案件由少年法庭處理，證據共用、人物對質、少年作證之程序在現行法找不到明文（少事法第三章「少年保護事件」是封閉體系）。
  4. 未審查實效：立法院從未要求司法院、法務部提出 §85 等條款的「適用情形專案報告」。

論述翻轉：國教盟不必主張「全新立法」，而應主張：

「成少共犯既有法源未被有效執行，請司法院、法務部公開現行條款的適用率、起訴率、量刑分布，並就偵查程序、競合處理、被害人保護建立配套程序法。」

政治效果：

  • 砍掉司法院「現行法已可處理」的擋箭牌
  • 砍掉兒少團體「修法傷少年保護」的反對論點
  • 把責任壓到「執行不力」而非「立法不足」
  • 同時為下一階段的程序法修法（增訂專章）鋪路

2. 司法院 115/5/22 修正草案 vs 國教盟訴求對照

2.1 司法院 5/22 草案三大主軸

  1. 少年刑事案件被害人訴訟參與制度
  2. 少年刑事案件假釋門檻分級
  3. 少年前案紀錄塗銷與「視為未曾受宣告」制度調整

  • 鐘宗霖廳長口頭（同一場）：「贊成成立犯罪防治觀護署」

3. 成少共犯結構性分析

3.1 現實供應鏈結構

〔上游〕跨國 / 組織化製造（毒品、詐騙劇本、洗錢通道）
        │
〔中游〕成年盤商 / 詐騙集團頭目 / 黑道組織首腦
        │
〔下游成年〕成年販運者 / 機房主管 / 中階幹部
        │
〔末端〕少年使用者 / 少年車手 / 少年運送 / 少年人頭
        │
        ▼
    制度斷裂處 ────→ 少事法保護傘
                      ─ 塗銷快（§83-1）
                      ─ 檢察官難直接訊問
                      ─ 少年作證程序不明
                      ─ 少年法庭與檢察官不對話

結構性套利：成年犯罪組織把少年當「法律屏蔽層」使用 — 風險轉嫁、責任稀釋、追訴困難。

3.2 制度斷裂的五個具體點

  1. 偵查發動：少年觸法後進入少年法庭，但與其共犯之成年人偵查由檢察官主導，兩條程序線無法定銜接機制。
  2. 證據共用：少年於少年法庭之自白 / 陳述能否作為成年共犯之證據？少事法不規範。
  3. 少年作證：成年共犯案件中傳喚少年作證，無強制陪同、心理評估、一站式偵訊規定（性侵害案件有，毒品 / 詐欺案件無）。
  4. 量刑落差：同案兩人，少年走保護處分（無前科）、成年走刑事審判（有前科），社會觀感上的「不公平感」會被放大利用為反少年司法的政治資本。
  5. 再犯防制：成年人服刑完畢後回頭吸收同一批少年，少事法與刑事執行法之間無強制通報機制。

5. 修法五大條文模組

模組 ① 曝險前置（少事法 §3）

現行（記憶版，需核對）國教盟建議擴增
1. 攜帶刀械無正當理由
2. 施用毒品或迷幻物品而尚未涉犯刑罰法律
3. 預備犯罪、未遂犯
（依 2019 修法精神，僅限三項曝險事由） 		+ 4. 參加不良組織或經常與有犯罪習性之人交往
+ 5. 受他人誘導、雇用、指使，運送、寄藏或交付毒品、贓物、詐欺所得財物或人頭帳戶

國教盟觀點 第 5 項是現有曝險定義最大盲區，正是車手少年、運毒少年被吸收的高風險前置態樣。

模組 ② 增訂「成少共犯案件特別程序」專章

建議放於少事法第四章之一（保護事件 vs 刑事事件之間），核心條款方向：

  • 定義條款：成少共犯案件 = 成年與少年共同涉犯特定犯罪（毒品、組織、洗錢、詐欺、人口販運、刑法殺傷詐欺等）
  • 偵查管轄分工：檢察官與少年法院共同偵辦時的卷證移交、證據共用、避免重複訊問
  • 少年作證保護：律師 / 法定代理人 / 社工強制陪同；訊問前心理評估；一站式偵訊、單面鏡、視訊作證、隔離詰問（參考性侵害犯罪防治法保護模式）
  • 卷證共用：少年法庭與成年法院認定事實衝突時的處理
  • 跨庭聯繫：少年法庭法官與檢察官就同案應有定期聯繫會議與書面紀錄

模組 ③ 既有加重條款活化 + 少年離團保護雙軌

重點：不是新增加重條款（既有條款已足），而是活化既有規定 + 配套少年端保護。

  • 要求司法院、法務部公布少事法 §85、毒品條例 §9、組織犯罪條例 §6 之適用率統計
  • 增訂少事法「離團保護方案」：少年若係受成年人吸收，得作為處分減輕事由；同時建立人身安全 + 安置 + 教育 + 心理 + 戒癮五合一方案
  • 政治話術：「重罰大人、保護孩子」 — 一句話打掉「加重會傷少年」的反對論點

模組 ④ 跨機關通報 + 統計透明

  • 成少共犯案件之成年部分判決確定後，強制回頭通報少年端後續處遇承辦機關
  • 司法院、法務部、警政署每年公布去識別化之成少共犯案件分類統計

模組 ⑤ 校園端配套（接軌兩層式檢測）

  • 兩層式檢測陽性即啟動成年端溯源
  • 教育部、警政、檢察、法務四方跨部會 SOP：校園發現一個依托咪酯個案 → 24 小時內啟動供應鏈溯源

6.2 結盟對象

對象立場預判國教盟可給的價值

警政署大概率支持提供基層執法痛點論述

6.3 預期反對論點與駁論

反對方論點駁論
加重將傷少年司法保護精神加重對象是成年加害者，少年端反而引入更強的離團保護方案
偵查程序開放會讓少年再受創傷一站式偵訊、心理評估、強制陪同本身就是保護升級
統計公開侵害少年隱私要求的是去識別化分類統計，不是個案揭露
應該繼續用「行政指引」處理就好違背行政院指示、違背平等保護原則
增訂專章將拖延整體修法五大模組可獨立成案併行審查
現行法已可處理（§85 等）正中下懷 — 那就請公布適用率與統計，證明真的「有用」

6.4 內部立場一致性問題（必須先講清楚）

成少共犯案件中，少年既是加害人、也常是被害人。建議國教盟內部定調：

  • 「被吸收的少年」走保護路線（離團方案、減輕事由）
  • 「主導或積極參與的少年」維持嚴格處遇路線
  • 分流標準 = 風險評估量表（既有訴求）

不先講清楚，外部會以「兩面下注」攻擊。
