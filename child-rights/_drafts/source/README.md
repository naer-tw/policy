# _drafts/source/ — 內部研究原始素材

本目錄存放**研究用原始檔**（政府公開資料、會議紀錄、新聞剪報、學者論文等）。

## 性質

- **內部使用**：供國教盟政策研究組引用，不對外發布。
- **noindex**：已於 `robots.txt` 設定 `Disallow: /child-rights/_drafts/`，搜尋引擎不索引。
- **無版權問題**：本目錄只存放政府公開資料、新聞報導摘要、學術論文摘要、會議公開紀錄等公共領域素材。
- **引用紀律**：對外發布之立場文件、新聞稿、公聽會書面意見，若引用本目錄素材，必須回到**原始官方來源**核對並引用之，不得引用本目錄之 .txt 版本路徑。

## 維護

新增素材時應同步：
1. 在本 README 加入檔案說明、來源、用途
2. 確認檔名含日期前綴（YYYY-MM-DD-）
3. 確認檔案不含個資、機密資料、未授權引用之他人未公開文件
