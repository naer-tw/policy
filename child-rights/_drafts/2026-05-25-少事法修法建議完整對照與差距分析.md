9. ❌ **成少共犯案件特別程序**（本報告核心）

## 3. 完整修法建議清單（按條文整理）

### 3.1 少年事件處理法（核心法規）

#### §3 曝險少年定義

| 來源 | 建議內容 |
| --- | --- |
| 國教盟第五大訴求第一層 | 增「(4) 參加不良組織」「(5) 受誘導運送毒品、贓物、詐欺所得財物或人頭帳戶」 |
| 司法院 323 公聽會口頭承諾 | 「(4) 參加不良組織」「(5) 經常與有犯罪習性之人交往」 |
| 林倩綺委員 11/27 書面 | 增手遊平台監管之招募態樣 |

**整合建議**：**現行 3 項 + 增 3 項 = 6 項**

```
§3 少年有下列情形之一者，由少年法院依本法處理之：
一、少年觸犯刑罰法律。
二、少年有下列情形之一，而認有保障其健全自我成長之必要者：
  (一) 攜帶刀械無正當理由（現行）
  (二) 施用毒品或迷幻物品而尚未涉犯刑罰法律（現行）
  (三) 預備犯罪、未遂犯而未涉刑罰（現行）
  (四) **參加不良組織或經常與有犯罪習性之人交往**（新增，司法院已承諾）
  (五) **受他人誘導、雇用、指使，運送、寄藏或交付毒品、贓物、詐欺所得財物或人頭帳戶**（新增，國教盟主張）
  (六) **受他人透過網路平台或社群媒體誘導加入犯罪組織或從事犯罪預備**（新增，林倩綺委員主張）
```

**整合建議**：草案的方向對，但程度不夠 — 應接受 5/22 草案精神，**進一步分級為 3-10 年**，並補入 §83-3、§83-4。

#### §85 成年人共犯加重（**核心：活化現有法條**）

| 來源 | 建議內容 |
| --- | --- |
| 國教盟第五大訴求第三層 | 立法院決議要求每年提出 §85 適用情形專案報告 |
| 警政署、法務部、司法院 | 從未公開 §85 起訴、定罪、量刑分布 |

**整合建議**：**不修條文本身，要求公開適用統計** — 這是國教盟「重罰大人」論述的核心。

#### 增訂第四章之一：成少共犯案件特別程序（**核心新章**）

| 章節 | 條文方向 |
| --- | --- |

## 7. 風險與反對論點

### 7.1 預期反對論點與駁論（v1.1 更新版）

| 反對方論點 | 駁論 |
| --- | --- |
| 加重將傷少年司法保護精神 | 加重對象是**成年加害者**，少年端反而引入更強的離團保護方案 |
| 偵查程序開放會讓少年再受創傷 | 一站式偵訊、心理評估、強制陪同**本身就是保護升級** |
| 統計公開侵害少年隱私 | 要求的是**去識別化分類統計**，不是個案揭露；何況警政署 11/27 已主動公開 109-113 年比例 |
| 應該繼續用「行政指引」處理就好 | 違背行政院指示、立法院質詢、監察院認證、平等保護原則 |
| 增訂專章將拖延整體修法 | 五大模組可**獨立成案併行審查** |
| 現行法已可處理（§85 等） | **正中下懷** — 那就請公布適用率與統計，證明真的「有用」 |
| CRC 第 40 條反對偵查特別程序 | **正中下懷** — CRC #24 GC 第 37、90 點正是要求「建立保護處遇與偵查並重的另外程序」。性侵害犯罪防治法之一站式偵訊從未被視為違反 CRC |
| 立委提案會打亂司法院草案節奏 | 司法院已 17 個月迴避修法、5/22 草案違背行政院指示，**立法院本來就應介入** |

### 7.2 內部立場一致性（必須先講清楚）

**成少共犯案件中，少年既是加害人、也常是被害人**：

- 「被吸收的少年」走保護路線（離團方案、減輕事由）
- 「主導或積極參與的少年」維持嚴格處遇路線
- 分流標準 = 風險評估量表（既有訴求）

不先講清楚，外部會以「兩面下注」攻擊。

## 8. 結論

**司法院 5/22 草案 vs 50+ 項修法建議：差距明確**

- ✅ 1 項符合方向：被害人訴訟參與
- △ 2 項部分符合：假釋門檻、塗銷觀察期
- ❌ 47+ 項落空

**最關鍵的 4 項**（最高優先序、最具殺傷力）：

1. **增訂第四章之一**（成少共犯案件特別程序）— 解決偵查割裂
2. **既有加重條款統計專案報告**（§85、毒品 §9、組犯 §6、詐欺犯罪危害防制條例）— 證明既有法不夠
3. **§3 曝險定義擴增**（4）（5）— 司法院已承諾，應立刻入法
4. **塗銷分級至 10 年 + §83-3 + §83-4** — 在司法院 5/22 草案基礎上加碼

**動員方向**：「學界共識 + 民間倡議 + 立委提案」三方共構，以立法院 11/27 公報、警政署 113 年統計、監察院新北案調查報告為三大證據基礎，要求立法院於 5/22 草案審議時**併案處理 50+ 項建議**，不接受司法院單方草案。
